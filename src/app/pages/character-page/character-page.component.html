Cómo llegan aquí los datos de tu personaje
  • Blizzard todavía no ofrece armería ni API pública para Forever (además, no hay reinos), así que esta web no puede buscar tu personaje por nombre.
  • Los datos salen del addon WowLevelingExport, incluido en esta guía. Lee en el juego tu equipo, talentos, nivel, experiencia, zona y mascota, y genera un texto para pegarlo aquí.
  • Es una foto del momento en que exportas: cuando cambies de equipo o subas de nivel, vuelve a escribir /exportpj y pega el texto nuevo.
  • El texto se guarda solo en este navegador. No se envía a ningún servidor.
  • Los objetos que aún no están en los datos de la beta salen con su nombre, pero sin icono ni tooltip. No hay modelo 3D del personaje: se muestra el equipo con sus iconos.
  1. Descarga el addon y descomprímelo en la carpeta Interface/AddOns de Forever, de forma que quede Interface/AddOns/WowLevelingExport.
  2. En el juego escribe /exportpj: se abre una ventana con el texto ya seleccionado.
  3. Pulsa Ctrl+C, vuelve aquí y pégalo{{ character() ? ' tras pulsar Cambiar personaje' : ' abajo' }}.
